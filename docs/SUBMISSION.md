# Проверка ТЗ и передача Ochen Composer

Основные функции реализованы. README описывает запуск и сравнение с ТЗ.
Автотесты и локальные SVG не заменяют ручную приёмку в настоящей Figma.

## Комплект

| Пункт задания | Материал | Оставшееся действие |
| --- | --- | --- |
| Запускаемый проект | dist/OchenComposer-review.zip: сборка и исходники | Разместить архив и передать ссылку |
| Репозиторий | https://github.com/MaksimovYuriy/OchenComposer | Опубликовать текущую версию и проверить доступ |
| Короткая демонстрация | Сценарий ниже | Записать видео или провести живой показ |
| Архитектура | README и ARCHITECTURE.md | Готово |
| AI-инструменты | README: Codex при разработке, OpenRouter в продукте | Дополнить, если использовались другие инструменты |
| Три композиции | examples/01-learning.svg, 02-growth.svg, 03-dialogue.svg | Желательно дополнить реальными экспортами Figma |

`npm run package` создаёт архив локально и ничего не загружает на GitHub, в Figma
или другое хранилище. В архиве нет личного ключа; проверяющий использует свой.

## Финальная ручная проверка

- [ ] Подтвердить происхождение и достаточность библиотеки относительно исходных
  20 иллюстраций. 10 названий × 4 варианта этого автоматически не доказывают.
- [ ] Распаковать архив в другую папку, импортировать manifest в Figma Desktop
  и пройти README без исходного Figma-файла и node_modules.
- [ ] Проверить названия офлайн, повторы, ошибки неизвестных компонентов,
  новые варианты, форматы и L/S.
- [ ] Проверить метафоры с отдельным ключом и зафиксировать результаты.
  catalog/metaphor-acceptance.json — смысловые ориентиры, не буквальный эталон.
- [ ] Пройти перенос, поворот, дублирование, удаление, слои и смену состояния.
- [ ] Проверить три схемы и загруженную палитру: разрешённые цвета, сохранение
  размеров, позиций и слоёв при повторной перекраске.
- [ ] Скачать SVG после ручной правки и импортировать обратно в Figma: проверить
  внешний вид, формат, цвета и отдельную векторную редактируемость предметов.
- [ ] Проверить неверный ключ/сбой сети/лимит: нет частичных фреймов и повреждения
  предыдущих композиций. Ключ не попал в демонстрацию и материалы.
- [ ] Приложить 2–3 реальных экспорта и короткую демонстрацию.
- [ ] Передать ссылки на репозиторий, архив и демонстрацию.

## Демонстрация на 2–3 минуты

1. Открыть пустой файл, запустить плагин и собрать «Книга, телефон, монета» без ИИ.
2. Изменить формат/L/S и создать отдельный вариант; предыдущая сцена сохраняется.
3. Выбрать предмет: сдвинуть, повернуть, дублировать, поднять слой, удалить копию.
4. Сменить цветное/монохромное состояние. Применить другую палитру, затем загрузить
   catalog/custom-palette.green.json и перекрасить композицию.
5. С заранее подключённым ключом ввести «Знания открывают возможности» в режиме ИИ.
   Показать объяснение и результат; не демонстрировать значение ключа.
6. Подготовить и скачать SVG, перетащить обратно в Figma, раскрыть Layers и показать
   отдельные векторные предметы.
7. Показать README: архитектуру, AI-инструменты, репозиторий и примеры.

Этот файл — сценарий и контрольный лист, а не запись выполненных действий.
Для асинхронной сдачи требуется фактическая демонстрация, а не только этот текст.
