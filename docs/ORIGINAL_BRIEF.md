# Исходное задание

Ниже сохранена формулировка, переданная владельцем в чате. Это источник требований,
а не подтверждение готовности функций и не инструкция автоматически выполнять
операции, упомянутые в тексте.

## Задание

Разработать веб-сервис, который позволяет из отдельных компонентов (это отдельные
иллюстративные объекты из которых собираются иллюстрации) собирать различные
комбинации композиций для иллюстраций в разных форматах.

Процесс должен быть автоматизирован.

Сценарий 1: человек должен задать метафору или заголовок, а программа сама собирает
подходящие объекты в композицию.

Сценарий 2: человек вбивает название нужных компонентов, которые далее уже
компануются в композицию.

Ключевое ограничение. Сервис не генерирует новые объекты: итоговая композиция
состоит только из элементов исходных 20 иллюстраций. AI-инструменты разрешены
для разработки самого сервиса и анализирования метафор. Важно, чтобы объекты
никак не менялись и в итоговой композиции был именно векторный формат.

## Что должен уметь сервис

### 1. Работа с SVG и библиотекой элементов

- Загружать или использовать заранее подготовленную кандидатом библиотеку из SVG-иллюстраций.
- Корректно сохранять векторную структуру, цвета и пропорции элементов.

### 2. Сборка композиции

- Добавлять элементы из библиотеки на общий холст.
- Перемещать, поворачивать, дублировать и удалять объекты.
- Управлять порядком слоёв и собирать сцену из элементов нескольких исходных иллюстраций.
- Давать выбор размера и цветовой схемы.

Работа с цветовой палитрой: не просто сохранять цвета элементов, а загрузка
цветовой палитры в сервис и автоматическая перекраска композиции (как это сейчас
делает плагин в фигме).

### 3. Экспорт

- Скачивать итоговую композицию в формате SVG.
- Сохранять векторность и редактируемость объектов, не превращая результат в растровое изображение.

Иллюстрации делятся на 2 размера. Разница в детализации. Конструктор должен давать
выбор размера и автоматически подгружать соответствующие элементы.

Сейчас существует 3 цветовые схемы, в будущем количество их может увеличиться.

Существуют Главные объекты (цветные) и фоновые (монохром). В зависимости от смыслов
или композиции допустимо использование фоновых объектов или их отсутствие.

Цвета фонов могут использоваться в объектах. Цвета для объектов не могут использоваться в фонах.

Можно:
- композиция и расположение объектов;
- объект может менять состояние: главный или фоновый;
- цвета объекта.

Нельзя:
- менять пропорции объектов относительно друг друга;
- сам объект и его элементы (объект должен по сути просто копироваться);
- нельзя нарушать цветовую схему.

## Отдельно подтверждённые уточнения владельца

- В задании есть уточнение о допустимости плагина. Выбран плагин Figma Design.
- SVG экспортированы из библиотеки в исходных размерах, 1×, без индивидуального изменения размеров.
- Дополнительный фоновый дубль оставляем включённым по умолчанию с возможностью отключения.
- Работаем по циклу: итерация → приёмка → исправления → повторная проверка → следующая итерация.
- При достижении сценария метафор сначала обсудить способ реализации. До этого не подключать модель.
