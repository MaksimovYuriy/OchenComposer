Ochen Composer

Подготовка библиотеки…

ИИ интерпретирует смысл и выбирает подходящую выполнимую композицию, адаптируя детали. Объяснение появится под запросом. Наружу отправятся фраза, текстовые правила и каталог с размерами, формат и seed — без SVG и документа. До 2 API-запросов на сборку: второй только для исправления некорректного плана. «Новый вариант» запускает новый подбор.

Настройки ИИ · OpenRouter

Ключ не добавлен. Для названий ключ не нужен.

openrouter/free выбирает доступную бесплатную модель; её ответы могут различаться. Можно указать конкретный ID с окончанием :free. Платного переключения нет.

Без отметки ключ хранится до закрытия плагина. Сохранение использует настройки Figma, а не защищённый менеджер паролей.

Создайте ключ на openrouter.ai/keys, вставьте и примените настройки. Бесплатные модели ограничены квотами и могут быть недоступны. Проверка ключа не проверяет качество модели.

Загружаем каталог…

Палитра новой сцены: Фиолетовая.

До 8 предметов через запятую или перенос строки. Повтор названия добавляет экземпляр. Повороты автоматические; у лампы и цветов угол 0°. Масштаб сцены общий.

Автоматически выбирается наиболее сбалансированная раскладка. Первый предмет задаёт фокус; размеры предметов относительно друг друга сохраняются. Новый вариант меняет расположение и создаёт отдельный фрейм. Для сцены без монохромных предметов выберите «Цветные» и отключите дубль.

Выберите композицию или её предмет в Figma.

Выбранный предмет

Выберите один предмет композиции в Figma.

Стрелки сдвигают на 10 px. Команды не пересобирают соседей. Смена состояния заменяет вложенную графику исходником, сохраняя трансформации.

Добавить в эту композицию

L/S и масштаб берутся из сцены. Если свободного места нет, команда отменяется. Вложенные пользовательские группы сначала разгруппируйте до уровня композиции.

Цветовая схема

Выберите композицию или один её предмет в Figma.

Выбор схемы задаёт цвета новой сборки. Кнопка перекрашивает только выбранную композицию, сохраняя предметы, позиции, углы и слои. Ручные цвета заменяются исходными цветовыми ролями.

Загрузить свою палитру

JSON с восемью подписанными ролями. Загрузите пример, измените HEX и импортируйте файл с новым id.

surface / mid / deep / paper доступны фону и предметам. accentLight / accentStrong / accentSoft / ink — только цветным предметам. Связанные стили, переменные и неизвестные цвета без сохранённых ролей требуют возврата к исходной структуре.

До 10 личных схем сохраняются в настройках плагина. Палитра композиции хранится также внутри документа; после перезапуска её можно продолжать использовать. Повторный импорт того же личного id обновляет запись, не перекрашивая старые сцены.

Скачать композицию

Выберите композицию или её предмет в Figma.

Экспортируется текущее состояние: цвета, расположение, повороты и порядок слоёв. Каждый предмет сохраняется отдельной векторной группой.

Скачать SVG

После изменений подготовьте файл заново. Для проверки перетащите скачанный SVG обратно в Figma и проверьте отдельные предметы.
